# 📦 Ensure apt packages Role

## 🎯 Purpose
This role ensures the installation of specified apt packages on target Linux hosts. 🐧

## 📋 Variables
- `apt_packages`: A list of packages to install, defined in `vars/main.yml` 📝

## 🚀 Usage
Include this role in your playbook to install the predefined list of packages. 

## 🛠️ Customization
Modify `vars/main.yml` to add or remove packages as needed. 🔧
